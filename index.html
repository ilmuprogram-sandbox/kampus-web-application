Responsif dan Aksesibilitas

  • Bagian 1

    Dasar Responsif

    Halaman menyesuaikan lebar layar: 1, 2, atau 3 kolom.

    • Meta viewport & box-sizing
    • Satuan relatif & gambar fleksibel
    • Media query mobile-first
    responsif-aksesibilitas/bagian-1.html
  • Bagian 2

    Dasar Aksesibilitas

    Halaman yang dapat dipakai dengan keyboard dan pembaca layar.

    • Skip link & fokus terlihat
    • Teks alt, kontras, tautan yang jelas
    • Label formulir & aria-describedby
    responsif-aksesibilitas/bagian-2.html
  • Bagian 3

    Responsif + Aksesibel

    Menggabungkan keduanya dalam satu halaman.

    • Menu ☰ dengan aria-expanded
    • Mode gelap & kurangi gerakan
    • Tabel gulir & notifikasi aria-live
    responsif-aksesibilitas/bagian-3.html
  • CSS

    CSS Responsive

    Teknik tata letak modern dengan CSS di berkas terpisah.

    • Flexbox & Grid auto-fit
    • grid-template-areas & clamp()
    • <picture> & container query
    css-responsive/index.html + style.css

💡 Tips saat praktik di kelas

  1. Lihat kodenya: klik kanan → View Page Source, atau tekan Cmd+Opt+U (Mac) / Ctrl+U (Windows).
  2. Uji responsif: buka DevTools (F12), lalu aktifkan mode perangkat dengan Cmd+Shift+M / Ctrl+Shift+M.
  3. Uji keyboard: letakkan mouse, lalu jelajahi halaman hanya dengan Tab, Shift+Tab, Enter, dan Esc.
  4. Uji aksesibilitas otomatis: DevTools → tab Lighthouse → centang Accessibility → Analyze page load.
